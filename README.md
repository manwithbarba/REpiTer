# REpiTer (Registros Epidemiológicos en Terreno)

REpiTer es una aplicación Android modular diseñada para la recolección de datos de salud en terreno, con un enfoque en el funcionamiento offline y la interoperabilidad mediante estándares HL7 FHIR.

## Características principales

- **Módulos adaptables**: EPH, ENFR, ENPreCoSP, Vacunación y Salud Mental.
- **Georreferenciación**: Captura automática de coordenadas GPS al guardar registros.
- **Interoperabilidad**: Exportación de datos en formato FHIR QuestionnaireResponse (JSON) y CSV.
- **Validación de Identidad**: Validación local de DNI y campos obligatorios.
- **Funcionamiento Offline**: No requiere conexión a internet para el relevamiento.
